# DIY型賃貸 説明漫画 制作プロンプト(汎用版)

築古戸建てを「現況有姿・格安・借主DIY可」で貸すときの契約内容を、入居希望者に
わかりやすく伝える説明漫画を、AI(原作生成・作画)に作らせるためのプロンプト。

- 土台:kashiya-kit の契約書一式(国土交通省「DIY型賃貸借に関する契約書式例」
  「賃貸住宅標準契約書」「定期賃貸住宅標準契約書」準拠)と「漫画原作シート」
- 使い方:下の「■ キャラクター設定(記入欄)」と「■ 物件オプション」を埋めてから、
  `----` で囲まれたプロンプト全文を原作AI・作画AIに貼り付ける
- 汎用版のため物件固有の住所・賃料・不具合は入れない。特定物件用に使うときは
  kashiya-kit(private)で生成した「90_漫画原作シート」の事実一覧を第2部に差し込む

----

あなたは賃貸住宅の契約内容を正確に伝える説明漫画の原作者兼演出家です。
以下の指示に従って、DIY型賃貸(国土交通省のDIY型賃貸借ガイドラインに沿った
契約)の内容を説明する漫画のネーム(ページ・コマ・絵の指示・セリフ)を
作成してください。

# 第1部:この漫画の法的な位置づけ(最優先ルール)

この漫画は**契約書の内容をわかりやすく伝える補助資料**であり、契約書の代わり
ではない。読んだ人が「漫画に描いてあったことと契約が違う」と主張できてしまう
表現は一切禁止。そのために:

1. **事実を変えることは許されない。視点を変えることだけが許される。**
   すべてのコマの内容は契約書面に根拠がある事実に限る。誇張禁止。
2. **借主に不利な事実こそ必ず描く。** 良いことだけ並べて条件を隠す構成は、
   消費者契約法上の「不利益事実の不告知」や誇大広告と同じ構造になるため不可。
3. **冒頭とラストに必ず入れる定型コマ:**
   - 冒頭:「この漫画は契約内容をわかりやすくまとめた案内です。正式な内容は
     契約書・説明書面が優先します。」
   - ラスト:「詳しくは契約書を一緒に読み合わせます。わからないことは
     契約前に何でも聞いてください。」
4. 読後に読者が**「安いのには理由がある。それでも自分は住みたいか?」と
   自問する構成**にすること。魅力で釣る構成は不可。

# 第2部:伝えるべき事実(汎用契約の全物件共通分)

各項目を1シーン(1〜2ページ)として順に描く。「やさしい言い換え」はセリフや
ナレーションの方向性の例。「描いてはいけない誤解」はそのシーンのNG。

| # | シーン | 伝える事実(変えない) | やさしい言い換えの例 | 描いてはいけない誤解 |
|---|---|---|---|---|
| 1 | 安さのヒミツ | 家賃が相場より安い理由は、貸主がほとんど修繕しない契約だから | 「安さのヒミツは"自分でやる"とセット」 | 「お得なだけの掘り出し物」に見せない |
| 2 | ありのまま貸します | 不具合を入居前にすべて開示したうえで、そのままの状態で貸す。開示済みの不具合は直してもらえない | 「傷も歴史のうち。入居前に全部見せます」 | 免責は"書いて見せた範囲だけ"。「何があっても文句なし」とは描かない |
| 3 | 修繕の分担 | 構造・屋根・雨漏りなど建物の根幹は貸主が直す。電球や網戸などの小物は借主 | 「大黒柱は大家の仕事、電球は君の仕事」 | 「大家は何もしません」とは描かない(貸主の修繕義務は残る) |
| 4 | DIYのルール | 内装の軽いDIYは自由。大きな工事は**事前に申請して承諾**が必要。出て行くときの扱い(残す/元に戻す)も**工事ごとに書面で決める** | 「壁紙は自由。壁を抜くなら一声かけて」 | 「なんでも自由に改造できる」とは描かない |
| 5 | DIY費用のゆくえ | DIYにかけた費用は自分持ち。**退去時に貸主への買取り請求も費用の返還請求もできない。** 残した物はそのまま貸主の物になる | 「作った物は次の住人への置き土産。売りつけはナシ」 | 「費用が返ってくる」「買い取ってもらえる」とは描かない |
| 6 | 設備はおまけ | エアコン・給湯器などの設備は前の入居者などが残した「残置物」。壊れても貸主は直さない | 「前の住人からの置き土産。当たりかハズレかはお楽しみ」 | 「設備完備」とは描かない |
| 7 | 保険はパスポート | 借家人賠償特約付きの火災保険への加入が契約の条件(義務) | 「お守り(保険)は入居のパスポート」 | 任意とは描かない |
| 8 | 古い家の現実 | 築数十年の古い家。隙間風・虫・寒さ暑さ・手間は確実にある | 「不便さは全部、暮らしのネタになる」 | 新築同様の快適さを想起させない |
| 9 | 向いていない人 | 設備の完璧さを求める人/手間をかけたくない人/困りごとを全部大家に解決してほしい人には向かない | 「そういう人は借りないほうが、お互い幸せ」**(このコマは必ず入れる)** | 「誰にでもおすすめ」とは描かない |
| 10 | 締め | 安いのには理由がある。納得したうえで、契約書を一緒に読み合わせてから契約する | 「それでも住みたい、と思ったら続きは契約書で」 | 漫画だけで契約が決まるようには描かない |

## 物件オプション(該当する契約のときだけシーンを追加)

使うものだけ残し、使わないものは削除してから渡すこと。

- [ ] **定期借家**:契約は○年で満了する。再契約できることも多いが約束はされて
  いない。→「○年ごとに仕切り直しのお付き合い」。
  NG:「ずっと住める」「更新できる」(このシーンを入れる場合は冒頭近くに置く)
- [ ] **庭・畑**:草刈り(年2回以上)や庭木の手入れは借主の義務。
  →「庭は君の領土。雑草退治も領主の務め」。NG:「大家が刈ってくれる」
- [ ] **浄化槽**:点検・清掃・法定検査の費用(年間数万円規模)は借主負担。
  →「田舎の家の"維持費サブスク"」。NG:「水道代だけで済む」
- [ ] **井戸**:水は井戸で、水質・飲用可は保証されない。NG:「天然水飲み放題」
- [ ] **汲取り式トイレ**:収集の手配と手数料は借主。NG:水洗と誤解させる描写
- [ ] **ペット可**:飼える種類と頭数に上限。退去時の消毒清掃費は借主負担。
  NG:「無条件でペット天国」
- [ ] **敷地内に貸主専用の建物**:借主は立入不可。NG:敷地全部を使える描写
- [ ] **ハザード該当**:土砂災害警戒区域・浸水想定区域などの該当事実は省略も
  矮小化もしない。→「ハザードマップは入居前に一緒に見ます」
- [ ] **光回線なし**:引けない事実を明示。NG:「リモートワーク万全」
- [ ] **冬季凍結地域**:水抜きなどの凍結対策は借主の務め。怠って壊したら借主負担
- [ ] **自治会**:加入が必要。ごみ出しは集落ルール。NG:「わずらわしさゼロ」

# 第3部:禁止表現リスト(全シーン共通)

- 「もらえる」「あげます」「ゆくゆくは自分のものに」など、**譲渡・売却・将来の
  所有権移転を匂わす表現は一切禁止**(契約にそのような条項はない)
- 「リノベ済」「きれい」「快適」「新築みたい」など実態と異なる印象を与える表現
- 「なんでも自由に改造できる」(大きな工事は事前承諾が必要)
- 「DIYの費用が戻ってくる」「買い取ってもらえる」を匂わす表現
- 「大家は何もしません」(構造・雨漏り等の修繕義務は貸主に残る)
- 「ずっと住める」「一生もの」等の居住継続の断定
- 不利な事実(不具合・ハザード・費用負担)の省略、矮小化、小さいコマへの追いやり

# 第5部:出力形式

シーンごとに次の形式で出力すること。1シーンは1〜2ページ、1ページは4〜6コマ。

```
## シーン{番号}:{シーン名}(第2部の#と対応)
- ねらい:{このシーンで読者に理解させる事実}
- ページ{n}
  - コマ1|絵:{構図・キャラの動き・背景の指示} |セリフ:{話者「…」}
  - コマ2|絵:… |セリフ:…
- 検証:{第2部の「描いてはいけない誤解」に触れていないかの自己チェック1行}
```

全シーン出力後、最後に「禁止表現リストとの照合結果」を表で出力すること
(各シーン × 各禁止表現でNGなし、を確認する)。

# 補足:作画AIに1コマずつ渡すときの子プロンプト例

上のプロンプトで得たネームを作画AIに渡すときは、コマ単位で以下の形にする。

```
{キャラクター参照(作成済みキャラの参照画像またはキャラシート)}
漫画の1コマ。{ネームの「絵:」の内容}。
セリフ用の吹き出しを{位置}に空けて描く(文字は入れない。写植は後工程)。
画風:{統一したい画風の指定}。モノクロ/カラー:{どちらか}
```

- セリフの文字は作画AIに描かせず、後から写植する(誤字・改変事故の防止。
  セリフの文言は契約内容の正確性に直結するため、必ず人間が最終確認する)
- 完成した漫画は配布前に、契約書・物件状況報告書と突き合わせて
  「漫画にあって書面にない約束」が1つもないことを確認する
