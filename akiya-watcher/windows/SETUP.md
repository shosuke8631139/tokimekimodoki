# かんたんセットアップ説明書 (Windows用)

むずかしい言葉を使わずに説明します。全部で15分くらいです。
※.batファイルの画面に出る文字はローマ字です(日本語だと文字化けするため)。

## ステップ1: Pythonを入れる (5分)

Python(パイソン)は、このツールを動かすためのエンジンです。無料です。

1. https://www.python.org/downloads/ を開く
2. 黄色い「Download Python 3.x.x」ボタンを押してダウンロード
3. ダウンロードしたファイルをダブルクリック
4. **一番大事**: 最初の画面の下にある
   「**Add python.exe to PATH**」に**必ずチェック**を入れる
5. 「Install Now」を押して待つ

## ステップ2: ツールの準備 (3分)

1. この `akiya-watcher` フォルダごと、好きな場所に置く(例: ドキュメントの中)
2. `windows` フォルダの中の `setup.bat` をダブルクリック
3. 黒い画面が出て文字が流れます。
   「SETUP KANRYOU」と出たら成功。何かキーを押して閉じる

## ステップ3: Gmailの合鍵を教える (3分)

※Gmailのアプリパスワード(16文字)を先に作っておいてください。
   作り方: https://myaccount.google.com/apppasswords
   (Googleアカウントの2段階認証がONになっている必要があります)

1. `windows` フォルダの `set_gmail_password.bat` をダブルクリック
2. アプリパスワードを貼り付けて Enter
3. 「HOZON SHIMASHITA」と出たら成功

そのあと、`config.yaml` をメモ帳で開いて2か所直します:
- `username: "your-address@gmail.com"` → 自分のGmailアドレスに変える
- その少し上の `gmail_portal_mail` の `enabled: false` → `enabled: true` に変える

## ステップ3.5: 健康診断 (30秒)

設定が合っているか、ツール自身に確認させることができます。

1. `windows` フォルダの `check.bat` をダブルクリック
2. ✅と❌で「何ができていて、何が足りないか」が日本語で出ます
3. ❌があれば、その行に書いてある通りに直してください

迷ったらこの診断を実行して、出てきた画面を送ってもらえれば私が読み解きます。

## ステップ4: 試しに1回動かす (1分)

1. `windows` フォルダの `run_once.bat` をダブルクリック
2. 黒い画面のあと、ブラウザで「物件台帳レポート」が開いたら成功!

うまくいかないときは、黒い画面に出た文字(エラー)を
スクリーンショットして相談してください。

## ステップ5: 自動で動くようにする (1分)

1. `windows` フォルダの `schedule_register.bat` をダブルクリック
2. これで「**3時間おきに見回り + 日曜朝8時にまとめ**」が自動になります

やめたいときは `schedule_remove.bat` をダブルクリック。

## 知っておいてほしいこと

- 自動の見回りは**パソコンの電源が入っているときだけ**動きます。
  スリープ中・電源オフ中は動きません(将来、クラウドに引っ越しも可能)
- 通知をスマホで受け取るには Slack の設定が必要です(別途案内します)。
  設定しなくても、レポート(data\report.html)はいつでも開けます
- Sumai空き家の見張りを始める前に、そのサイトの利用規約を一度確認します
  (最初の実行のときに一緒にやりましょう)
