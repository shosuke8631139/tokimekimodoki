# 卒業制作 設計書 — 物件よみとりAI(2つの目スコアラー)

AIドリブンスクールの卒業制作。**毎日実際に使っている本番システム
(空き家ウォッチャー)に、AIの「読解層」を追加する**プロジェクト。

## 一言でいうと

毎朝届く物件メールの1件1件に、AIが2つの点数と理由1行を付ける。

```
【新着】肝付町 ○○ 98万円
  仕入れ点 78 「家財残置・現状渡しの文言あり。掲載4ヶ月で値下げ済み」
  出口点   62 「平屋・縁側と庭が写真2枚目に。空港まで車60分が減点」
```

- **仕入れ点(困り気配)** = 売主がこの家を面倒がっている度合い。
  高いほど「残置物ごと・安く」の交渉が通りやすい
- **出口点(海外ウケ)** = 貸す/売る出口の広さ。国内賃貸に加え、
  海外の空き家買い手(AkiyaMart等で実例あり)や在留外国人への
  出口が開くかどうか

狙い: ウォッチャーが「安く買える確率」と「高く出せる確率」を
同時に測る道具になる。判断は今まで通り人間(スコアは並べるだけ)。

## なぜ卒業制作としてこれか

- 架空のデモではなく、実在の事業で本番稼働している(毎日メールが届く)
- 「毎日使う」が構造的に保証される(使わない自由がない)
- 実データ・実運用・実金額で発表できる

## アーキテクチャ(既存に乗せる)

```
scrapers → models.Listing → criteria.py(規則ベースの既存スコア)
                          → ai_reader.py(新規: Claude APIで2軸採点) ← ここを作る
                          → storage.py(点数と理由をDBにキャッシュ)
                          → notify.py / report.py(メールに2点数を表示)
```

設計方針:
- **新着・変更があった物件だけ**APIに投げる(コスト管理。全件毎日は投げない)
- 結果はDBに保存し、再巡回では再利用する
- APIキーは環境変数 `ANTHROPIC_API_KEY`(GitHub Actions は Secrets)。
  リポジトリに書かない
- モデルは安価なもの(Haiku系)で開始。月数百円想定
- AI呼び出しが失敗しても巡回・通知は止めない(点数なしで送る)
- テストはAPIをモックして全緑を維持

## 採点基準(ルーブリック) — 下書き

※ NotebookLMで収集中の国内外事例を受け取り次第、ここを確定させる。

### 仕入れ点(売主の困り気配) 0-100

加点:
- 残置物・家財に関する文言(「残置物あり」「現状渡し」「家財はそのまま」)
- 長期掲載(90日以上)・値下げ履歴あり
- 遠方管理の気配(「県外在住のため」「管理できず」)
- 相続の気配(「相続した実家」「父母が住んでいた」)
- 付属建物(蔵・納屋・倉庫)= 中身が面倒の塊に見えている可能性
減点:
- リフォーム済み・ハウスクリーニング済み(売主が手をかけた=強気)
- 業者売主の気配

### 出口点(出口の広さ) 0-100

加点:
- 古民家意匠: 梁・縁側・土間・蔵・庭・畳・平屋(写真/文章から)
- アクセス: 鹿児島空港30分圏(霧島)・新幹線駅15分圏(出水・川内)
- 環境: 温泉地名・海/山/桜島ビュー
- 価格300万円以下(海外現金買いのスイートスポット)
- ペット可にしやすい戸建て・駐車場あり(国内賃貸の既存の型)
減点:
- 借地権・再建築不可・ハザード該当
- 過度なリフォームで古さが消えている(海外勢は古さを買いに来る)

## 作る順番

- **フェーズ0**: さつま町・霧島スクレイパーを本流へマージ→巡回実行→
  メール確認(前セッションからの持ち越し。先にパイプを太くする)
- **フェーズ1**: ai_reader.py で仕入れ点(文章のみ)。メール表示まで
- **フェーズ2**: 出口点を追加(2軸完成)。NotebookLM事例でルーブリック確定
- **フェーズ3**(余力): 写真の読解(古民家意匠・蔵の検出)
- **フェーズ4**(発表用の飛び道具・余力): しゃべる台帳 —
  電話・現地調査後に音声メモ→AIが構造化→watchlistのnoteに自動追記

## 事業側の関連決定(2026-08-01 セッション)

- 出口戦略: 「まず貸す→実績を作る→免責+告知書で売る」が標準ルート。
  売値下限 = 年間家賃÷15%(利回り売り)。売却は年1件まで(宅建業法の
  反復継続を踏まないため。非業者だから免責特約が使える)
- 海外向け売却は「年1売却」の時だけ起動する上乗せチャネル
  (英語圏への掲載は地元からは見えない=目立たない方針と両立)
- 在留外国人労働者向けの法人借り上げ(登録支援機関・農業法人)は
  挨拶キットの宛先に追加する(出水・大隅)
