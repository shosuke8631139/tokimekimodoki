使いはじめる前に ── 4つのルール

  1. 渡すのはすべて写し(コピー)。原本は別封筒に入れて持参し、求められたら見せる(渡さない)。
  2. A4片面で印刷し、通し番号の順番を崩さない。同じものを2部(自分用・先生用)用意する。
  3. 本文には事実だけを書く。気持ち・評価(ひどい、騙された等)は第8章の専用欄にだけ書く。
  4. 全ページをスキャンして1つのPDFにもまとめておく(例:20260722_ベランダ工事相談資料_氏名.pdf)。

記入のしかた

  • グレーの行・枠は記入例。固有名詞と数字を自分のものに差し替えるイメージで書く。
  • わからない欄は空欄にせず「不明」と書く。それ自体が先生への大事な情報。
  • 日付は3段階で正直に:①断定(証拠で確認済み)②「○月上旬頃」(記憶)③不明。
  • 相手の発言は要約せず、カギ括弧で原文のまま(例:「来週必ず行きます」と言った)。

請求額について知っておくこと。施工済み部分があなたの利益になっている場合、法律上は「支払額の全額」ではなく「支払額−出来高」の返還になるのが原則です(民法634条)。最終的な請求額(訴額)は先生と一緒に決めます。140万円以下かどうかで先生が代理できるかが変わります(第1章)。遅延損害金(法定利率年3%)も付けて請求できます。

B-1 この事件の法律上の型

  • 型:請負契約の債務不履行 → 催告して相当期間を待つ → 契約解除(民法541条)→ 支払済み金の返還(民法545条)+損害賠償(民法415条)。
  • 順序が大事:「催告 → 相当期間の経過 → 解除の意思表示」。LINEで完成を求めた履歴も催告の証拠になります。
  • 業者が完全に音信不通・履行拒絶なら、催告なしの解除(民法542条)を主張できる場合もあります。

B-2 司法書士に頼める範囲(重要)

  • 認定司法書士は、簡易裁判所の事件で請求額140万円以下なら、弁護士と同じように訴訟代理・和解交渉ができます。
  • 140万円を超える場合は、①弁護士に依頼する、②本人訴訟にして司法書士に訴状などの書類作成を支援してもらう、の二択になります。
  • 注意:訴訟の途中で相手から出来高の反訴が来るなどして140万円を超えると、司法書士は途中で降りざるを得ません。最初に見通しを聞いておきましょう。
  • 請求額60万円以下なら、原則1回の審理で終わる少額訴訟も選べます(相手の希望で通常訴訟に移ることがあります)。

B-3 時効(急ぐべき理由)

  • 債務不履行にもとづく請求は「権利を行使できると知った時から5年」で時効にかかります。工事放棄が確定した頃が起算のめやすです。
  • 施工済み部分に欠陥がある場合(契約不適合)は「知った時から1年以内」に相手へ通知が必要です。放置せず早めに動きましょう。

B-4 訴訟以外の相談・解決窓口

  • 住まいるダイヤル(0570-016-100):国土交通大臣指定の住宅相談窓口。一級建築士による電話相談、弁護士+建築士の無料対面相談があります。
  • 建設工事紛争審査会(国・都道府県):建設工事の請負紛争専門のあっせん・調停・仲裁。
  • 消費生活センター(188)、各司法書士会・弁護士会の相談窓口。
  • ただし、相手が話し合いに応じない場合これらの手続は機能しないため、連絡が取れない本件のようなケースでは訴訟を軸に検討するのが現実的です。

特に大事な3つのポイント

請求額140万円が分かれ目。認定司法書士が裁判の代理をできるのは簡易裁判所・請求額140万円以下まで。支払額を整理した段階で「司法書士に代理を頼めるか、弁護士か」の見通しが立ちます。
事実と感情の分離。時系列表には事実だけ(相手の発言はカギ括弧で原文のまま)を書き、気持ちは第8章の専用欄だけに。これが「裁判資料として使える」と感じてもらえる最大の要因です。
