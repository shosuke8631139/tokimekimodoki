# モドキクエストII 〜ふっかつのじゅもんはいらない〜

ドラゴンクエストIIを分析し、その構造(3人パーティ・船・紋章集め・ラスボス連戦)を
オリジナルの世界・キャラ・モンスターで凝縮再現したコマンドRPG。プレイ時間は30〜60分。

## DQ2の何を再現し、何を直したか

**再現した骨格**
- 仲間が旅の途中で増える(物理一筋の主人公 → 万能の王子 → 呪文特化の王女)
- 船の入手で行動範囲が一気に広がる
- 紋章を集めて最終ダンジョンへ/ラスボスの正体連戦(ハーゴン→シドー方式のパロディ)
- グループ出現するモンスターとのコマンド戦闘、画面フラッシュ・シェイクの戦闘演出

**遊びやすくした点(QoL)**
- ふっかつのじゅもん(52文字)→ **オートセーブ**(マップ移動・宿・レベルアップ時)
- サマルトリア王子のたらい回し → 仲間は**言われた場所で寝てる**(1手で見つかる)
- 全滅時の所持金半減 → **没収なし**、城で全回復して再開
- 高いエンカウント率 → 低め+「にげる」高成功率
- 今なにをすべきか分からない → **クエストログ常時表示**
- レベルアップで全回復/装備は購入時に自動装備・旧装備は自動下取り
- ロンダルキア級の終盤理不尽 → 適正レベルなら勝率8割になるよう数値調整済み
  (ボスは2回行動。低レベル挑戦はちゃんと負けます)

## 操作

矢印キー/WASD移動、ぶつかると話す/調べる、Enter/Z決定、Esc/Xメニュー。
スマホはオンスクリーンパッド対応。

# ときめきモドキ 〜ずっとズレてるDays〜

ブラウザで遊べる、ときめきメモリアル風(ギャグ寄り)恋愛シミュレーションゲーム。
ビルド不要・サーバー不要。**`index.html` をダブルクリックするだけで遊べます。**

## 遊び方

- 高校3年間 = **36ターン**。毎ターン、コマンドを1つ選びます。
  - 📖 勉強 / 🏃 運動 / ✨ おしゃれ / 🧠 読書 → 対応パラメータが上がる(ストレスも少し上がる)
  - 😴 休む → ストレスが下がる
  - 💌 遊びに誘う → 選んだ相手の好感度が上がる(その子の好きなパラメータが高いほど効果大)
- 好感度が **40 / 70** に達すると個別イベントが発生。
- 卒業時に好感度 **80以上** の相手がいれば告白イベントへ……ただし毎回、何かしら事故ります。
- **ストレスが100になると即ゲームオーバー**(笑えるけど取り返しのつかないやつ)。

## 攻略キャラ

| キャラ | 属性 | 致命的なズレ | 好きなパラメータ |
|---|---|---|---|
| 📚 小日向しおり | 図書委員 | 趣味が爆弾処理 | 雑学 |
| 🥋 護堂寺豪鬼丸 | 番長 | 敬語でしか話せない | 運動 |
| 🌟 星野ひかり | 転校生 | 自称17歳(実は45歳) | 容姿 |

## 爆弾システム(パロディ)

出会ったキャラを **6ターン放置**すると、頭上に物理的な爆弾が出現します。
3ターン以内に構わないと爆発し、全員の好感度が下がります。
ただし、しおりの好感度が60以上あると、趣味で勝手に解除してくれることがあります
(本人の爆弾は「解除する気が起きない」ため対象外)。

## エンディング(全7種)

1. しおりエンド(告白中に伝説の樹が爆発)
2. 番長エンド(告白が稟議書で届く)
3. ひかりエンド(強風で住民票が舞う)
4. 全員攻略 → 修羅場爆発エンド
5. 友情エンド(屋上で焼きそばパン)
6. ぼっち → 伝説の樹エンド「おまえはワシが育てた」
7. **絶対バッドエンド**:ストレス過多で28年昏睡 → 45歳で目覚め、「転校生」として高校をやり直すループエンド

## ファイル構成

```
index.html      画面構造(タイトル / ゲーム / イベントモーダル / エンディング)
css/style.css   レトロギャルゲ風UI
js/data.js      キャラ・イベント・選択肢・エンディングの全テキストデータ
js/game.js      状態管理・ターン進行・爆弾・エンディング判定ロジック
js/ui.js        DOM描画とイベントキュー制御
```

`file://` で直接開いても動くよう、ES Modules は使わず素の `<script>` タグで読み込んでいます。
イベントの追加は `js/data.js` にデータを足すだけでできます。

# 人生モドキ 〜どこで曲がっても後悔する〜

ファミコン版『人生ゲーム』(タカラ)を分析し、その骨格(ルーレット・ルート分岐・
職業カード・給料日・株・保険・億万長者の館)をオリジナルの内容で再現した
ボードゲーム。あなた + CPU最大3人、1ゲーム10〜15分。

## FC版『人生ゲーム』の何を再現し、何を直したか

**再現した骨格**
- サイコロではなく **ルーレット(1〜10)を自分で止める**(等速で回り続け、止めた瞬間の位置で決まる)
- **進路の分岐**:大学(遠回り・高給)か 就職(近道・低給)か → 中盤にもう一度、家庭か仕事か
- **職業で給料が決まり、給料日マスで受け取る**(通過しただけでも受給)
- 結婚・出産で車に家族が乗る / マイホーム / 株 / 保険 / 事故 / 転職 / 全員から徴収マス
- 払えないときは **約束手形**(借金)。ゴール時に利息1.5倍で清算
- ゴールは **億万長者の館**、最下位は農場。順位は現金ではなく **総資産**で決まる

**遊びやすくした点(QoL)**
- 「誰が勝っているか暗算できない」→ **暫定資産で常時ランキング表示**(株は見込み計算)
- 「運だけで決まって選択の余地がない」→ 分岐以外に **二択マス**を追加
  (安全な一手 vs 勝負手。確率と金額を必ず明示するので、納得して負けられる)
- 「就職・結婚マスにちょうど止まらないと人生が始まらない」→ **節目のマスは必ず止まる**
  (逆に学費のような避けられない出費は、通過しただけでも発生する)
- 「CPUの手番が長い」→ **CPUを はやくする** チェックで一気に進む
- 「破産して以降ずっと消化試合」→ 借金でも脱落せず、最後まで逆転可能
- 「CPUが何を考えているか分からない」→ CPUに性格(何にでも手を出す / とにかく守る / 1円も出したくない)を持たせて明示
- ゴールした人を待たせない(先着順に賞金、残りは自動で進行)

## バランス調整(自動プレイで実測)

分岐が「実質一択」にならないよう、学費・給料・家族ボーナスを自動対戦にかけて
調整しました。下は4人が**別々のルート**を通って500ゲーム対戦した結果です。

| ルート | マス数 | 平均総資産 | 平均着順 | 1位率 |
|---|---|---|---|---|
| 大学 → 家庭 | 54 | 3,709万 | 3.01位 | 27% |
| 大学 → 仕事 | 50 | 3,748万 | 2.43位 | 30% |
| 就職 → 家庭 | 48 | 3,611万 | 2.71位 | 20% |
| 就職 → 仕事 | 44 | 3,758万 | 1.86位 | 23% |

4人ゲームの基準値は25%。**遠回りは資産が伸びるが着順が落ちる**という交換に
なっていて、どのルートも支配的ではありません。別途400ゲームを通しで走らせて、
例外ゼロ・就職できずに終わる人ゼロ(1,600人中)を確認しています。

なお1ゲームで判断を求められるのは、分岐2回 + 二択マス(全66マス中17マス)に
止まった回数。残りはルーレット任せです — そこは本家の味なので残しました。

## グラフィック

ファミコン実機の流儀で、盤面は **280x210 の低解像度で描いて CSS 側でドット拡大**
(`image-rendering: pixelated`)。スプライトはモドキクエストIIと同じ
テキストグリッド定義(1文字=1ドット)です。

- コマは車ではなく **2フレーム歩行アニメで歩くドット絵キャラ**。待機中も小さく弾む
- 結婚・出産すると **配偶者と子どもが後ろをぞろぞろ付いて歩く**(足跡を辿る追従)
- マスは上面+前面の **立体タイル**、種類ごとに自作ドットアイコン
- ゴールには **旗がはためく城**。誰かがゴールすると紙吹雪が舞う
- 木・流れる雲と地面に落ちる影・CRT風スキャンライン・手番マスの点滅枠

## 操作

ルーレットの「まわす」→「とめる!」を押すだけ。Enter / Z / スペースでも進みます。
分岐と二択はボタンで選択。スマホは縦並びレイアウトに切り替わります。

## ファイル構成

```
jinsei/index.html      画面構造(タイトル / 盤面 / ルーレット / 結果発表)
jinsei/css/style.css   カジノフェルト風UI
jinsei/js/data.js      職業・全マスのデータとテキスト(バンド単位で定義)
jinsei/js/game.js      盤面生成・移動・マス効果・CPU思考・総資産の清算
jinsei/js/board.js     ドット絵描画(280x210で描いてCSS拡大。歩くキャラ・立体マス・城・紙吹雪)
jinsei/js/ui.js        ルーレット・メッセージ送り・パネル・進行ループ
```

マスを増やすときは `js/data.js` の `BOARD_BANDS` に足すだけで、道の接続と
分岐は `buildBoard()` が自動で組み立てます(`stop` で必ず止まるマス、
`always` で通過でも効くマスになります)。
