# kashiya-kit — 築古戸建て「現況有姿・格安・DIY可」賃貸の書面ジェネレータ

築古戸建てを「現況有姿・格安・借主DIY可」で貸すための契約書一式と漫画原作シートを、
物件ごとの設定ファイル(YAML)から生成する。複数物件に使い回せる汎用テンプレート。

## ⚠️ 実データを絶対にコミットしないこと

**このリポジトリは公開リポジトリである。** 実物件の config には住所・賃料が、
生成書面には借主・保証人の氏名・連絡先を記入する欄が含まれる。

- git で追跡してよいのは **架空データの `config/property_sample.yaml` のみ**
- 実物件の config(`property_XXX.yaml`)と `output/` は `.gitignore` で除外済み
- `build.py` は実行時に追跡状態を検査し、コミットされ得る状態ならエラーで停止する
- 署名済み書面のスキャンデータ等もこのリポジトリには置かない

## 使い方

```bash
pip install -r requirements.txt
cp config/property_sample.yaml config/property_001.yaml   # 実物件用にコピーして編集
python3 build.py config/property_001.yaml
```

`output/property_001/` に Markdown 原本(`md/`)と A4 印刷用 HTML(`html/`)が生成される。
HTML をブラウザで開いて印刷する。Markdown は素直な構造(ATX見出し・パイプ表)なので、
将来 pandoc で docx 等へ変換できる。

## 生成される書面

| ファイル | 内容 |
|---|---|
| 00_手順書 | 貸主向け運用手順(定期借家の事前説明、保証人への説明、保険、終了通知など) |
| 01_賃貸借契約書 | 定期借家/普通借家を config で切替。特約込み |
| 02_定期借家事前説明書 | 借地借家法38条3項の事前説明書面(定期借家のときのみ生成) |
| 03_DIY合意書 | DIY工事の承諾手続・明渡し時の取扱い・所有権帰属 |
| 04_DIY申請書兼承諾書 | 工事1件ごとの申請・承諾様式+累積記録の別表 |
| 05_物件状況報告書 | 様式固定・中身は現地記入。既知の不具合は config から転記 |
| 06_修繕区分表 | config(浄化槽・井戸・庭など)に応じて行が増減 |
| 07_入居時チェックリスト | 写真記録欄つき現況確認 |
| 90_漫画原作シート | 別のAIが契約書を読まずに描ける情報+禁止表現・トーン指示 |
| 99_専門家レビュー事項 | このまま使わず、専門家に見せるべき箇所の一覧 |

## 設計上の約束(変更しないこと)

- 物件固有の情報はテンプレートにハードコードしない。すべて config から流し込む
- 該当しない条項(浄化槽・ペット等)は条項ごと出力しない。空欄を残さない
- 修繕義務の全部免除はしない(消費者契約法10条)。構造・屋根・雨漏り・給排水本管・
  シロアリ構造被害は貸主負担で固定
- 工作物責任(民法717条)の免責条項は書かない。対策は施設賠償責任保険(手順書参照)
- 譲渡・売却・将来の所有権移転に関する条項・表現は入れない
- 個人連帯保証を使う場合、極度額が未記入だとビルドエラーになる(民法465条の2)

## 準拠資料

- 国交省「DIY型賃貸借に関する契約書式例」・「家主向けDIY型賃貸借 実務の手引き」
- 国交省「賃貸住宅標準契約書 平成30年3月版」

**生成された書面は「案」であり、使用前に `99_専門家レビュー事項` に沿って
弁護士等のレビューを受けること。**
